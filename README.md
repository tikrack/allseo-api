# ALL SEO API
پروژه شبیه سازی api سایت allseo.ir

## مراحل اجرای پروژه
در ابتدا اطلاعات خود را داخل فایل info.json تکمیل کرده 

فیلد url:
آدرس سایتی که قصد بررسی انرا دارید

فیلد suite:
این فیلد نحوه تحلیل سایت را مشخص میکند که میتواند به صورت جنرال تست یا کارآگاهی باشد
در صورتی که مقدار برابر `general` باشد نوع جنرا انتخاب شده
و در صورتی که مقدار را برابر ‍‍‍‍`detective` باشد حالت کاراگاهی انتخاب میشود

در مرحله بعد کافیست که فایل `index.js` را صدا بزنید که از طریق دستورات زیر میتوانید این کار را انجام دهید
پیش نیاز اجرا این است که `nodejs` روی سیستم شما نصب باشد

## دستورات اجرا

Nodejs:
```
node index.js
```

Npm:
```
npm run start
```
