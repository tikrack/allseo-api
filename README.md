# AllSEO Analysis CLI Tool 🚀

یک ابزار خط فرمان (CLI) سبک، ماژولار و سریع به زبان Node.js جهت خودکارسازی و ارسال درخواست‌های آنالیز وب‌سایت به سیستم آنالیزور **AllSEO (allseo.ir)** بدون نیاز به مرورگر (Headless API Simulation).

این پروژه با مدیریت پویای توکن CSRF و کوکی‌های نشست، امکان می‌دهد لیستی از وب‌سایت‌ها را به‌صورت دسته‌ای (Batch) آنالیز کرده و لینک گزارش نهایی را مستقیماً در ترمینال دریافت کنید.

---

## ✨ ویژگی‌های کلیدی

- **بدون وابستگی خارجی (Zero Dependency):** استفاده از `fetch` بومی برای ارسال درخواست‌ها، بدون نیاز به کتابخانه‌هایی مانند Axios یا Request.
- **مدیریت پویای CSRF:** استخراج خودکار `csrfmiddlewaretoken` و کوکی نشست Django از پاسخ سرور.
- **پشتیبانی از پردازش دسته‌ای (Batch Processing):** امکان تعریف چند وب‌سایت در فایل کانفیگ و آنالیز متوالی آن‌ها.
- **پردازش Sequential:** ارسال درخواست‌ها به‌صورت متوالی برای کاهش فشار روی سرویس هدف و جلوگیری از ارسال همزمان درخواست‌ها.
- **نمایش خروجی زیبا (Interactive CLI UI):** نمایش نتایج در قالب کارت‌های ترمینال با استفاده از کدهای ANSI و کاراکترهای ASCII.
- **سازگاری با Runtimeهای مدرن:** قابلیت اجرا در محیط‌های Node.js و Bun.

# 🚀 راهنمای راه‌اندازی و استفاده

## پیش‌نیازها

یکی از Runtimeهای زیر را روی سیستم خود نصب داشته باشید:

- **Node.js نسخه ۱۸ یا بالاتر** برای پشتیبانی از `fetch` بومی
- **Bun** نسخه‌های مدرن

---

## 1. پیکربندی وب‌سایت‌ها

اطلاعات وب‌سایت‌های موردنظر خود را در فایل `info.json` در ریشه پروژه قرار دهید.

ساختار فایل به‌صورت آرایه‌ای از آبجکت‌ها است:

```json
[
  {
    "name": "ArmaghanKashan",
    "url": "https://armaghankashan.com/",
    "suite": "general"
  },
  {
    "name": "SalehMarket",
    "url": "https://salehmarket.com/",
    "suite": "detective"
  }
]
```

### توضیحات پارامترها

| پارامتر | نوع داده | توضیحات |
|---|---|---|
| `name` | `String` | نام نمایشی پروژه در خروجی ترمینال |
| `url` | `URL` | آدرس کامل وب‌سایت هدف به همراه پروتکل `http://` یا `https://` |
| `suite` | `Enum` | نوع آنالیز؛ مقدار `general` برای آنالیز عمومی و `detective` برای آنالیز عمیق |

---

## 2. نصب وابستگی‌ها

این پروژه در نسخه فعلی وابستگی خارجی ندارد.

در صورت وجود فایل `package.json`، می‌توانید برای آماده‌سازی محیط پروژه دستور زیر را اجرا کنید:

```bash
npm install
```

> توجه: اجرای `npm install` برای خود کد اصلی ضروری نیست و تنها در صورت اضافه شدن وابستگی‌های پروژه موردنیاز خواهد بود.

---

## 3. اجرای پروژه

### اجرای مستقیم با Node.js

روش پیشنهادی:

```bash
node index.js
```

### اجرای با NPM

در صورتی که اسکریپت `start` در `package.json` تعریف شده باشد:


# ⚙️ سازوکار فنی و معماری برنامه

فرآیند اجرای برنامه به چند مرحله اصلی تقسیم می‌شود.

## 1. دریافت توکن CSRF و کوکی نشست

ماژول `csrf-token.js` صفحه اصلی AllSEO را درخواست می‌کند.

سپس:

1. مقدار `csrfmiddlewaretoken` را از فرم HTML استخراج می‌کند.
2. کوکی نشست اختصاص داده‌شده توسط سرور را از هدرهای پاسخ دریافت می‌کند.
3. توکن و کوکی را برای مرحله بعد آماده می‌کند.

این مرحله برای شبیه‌سازی صحیح یک نشست معتبر در درخواست بعدی استفاده می‌شود.

---

## 2. ارسال درخواست تحلیل

ماژول `analyzer.js` درخواست تحلیل را به سرویس AllSEO ارسال می‌کند.

اطلاعات موردنیاز درخواست شامل مواردی مانند:

- آدرس وب‌سایت هدف
- نوع آنالیز (`suite`)
- توکن CSRF
- کوکی نشست
- هدر `X-CSRFToken`

داده‌های فرم نیز با فرمت زیر ارسال می‌شوند:

```text
application/x-www-form-urlencoded
```

---

## 3. استخراج لینک گزارش نهایی

پس از ارسال درخواست، پاسخ سرور بررسی می‌شود.

سیستم با بررسی محتوای پاسخ، لینک گزارش نهایی SEO را استخراج می‌کند. در صورت وجود تگ Canonical مانند نمونه زیر:

```html
<link rel="canonical" href="https://allseo.ir/...">
```

آدرس گزارش از مقدار `href` استخراج شده و به مرحله نمایش نتیجه ارسال می‌شود.

---

## 4. نمایش نتیجه در ترمینال

پس از اتمام تحلیل هر وب‌سایت، ماژول `response.js` نتیجه را در ترمینال نمایش می‌دهد.

تابع `basicResponse` به‌صورت پویا اندازه کادر خروجی را بر اساس طول لینک گزارش تنظیم می‌کند تا نتیجه در قالب یک کارت خوانا نمایش داده شود.

نمونه خروجی:

```text
┌──────────────────────────────────────────────────────────────┐
│ Website: ArmaghanKashan                                      │
│ Status:  Analysis Completed                                  │
│ Report:  https://allseo.ir/...                               │
└──────────────────────────────────────────────────────────────┘
```

# ⚠️ نکات مهم و سلب مسئولیت

## محدودیت نرخ درخواست (Rate Limit)

برای کاهش احتمال ایجاد فشار روی سرویس هدف یا مسدود شدن موقت IP، پردازش وب‌سایت‌ها به‌صورت **Sequential** طراحی شده است.

یعنی درخواست‌ها به‌صورت متوالی ارسال می‌شوند و چند درخواست به‌صورت همزمان اجرا نمی‌شوند.

---

## تغییرات ساختار سایت AllSEO

این ابزار به ساختار فعلی HTML و فرم‌های سرویس هدف وابسته است.

در صورت تغییر مواردی مانند:

- ساختار فرم‌ها
- نام فیلدها
- نحوه تولید CSRF Token
- ساختار پاسخ
- تگ Canonical
- مسیرهای API یا Endpointها

ممکن است لازم باشد Regexها یا منطق استخراج اطلاعات در فایل‌های زیر به‌روزرسانی شوند:

```text
csrf-token.js
analyzer.js
```
